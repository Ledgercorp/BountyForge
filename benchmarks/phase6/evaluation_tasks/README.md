# Sealed owned maintenance evaluation

Four independently authored Python maintenance cases, created 2026-10-21 by
an evaluation agent separated from repair implementation. These are original
owned source and acceptance tests, not retrieved repositories or historical
fixes. BountyForge's existing MIT licensing applies. The manifest pins every
source and test file by SHA-256 and records the provenance and split.

Do not expose case details to repair implementation until that implementation
and its development protocol are committed and frozen. Do not use these cases
for prompt iteration and then call a rerun a fresh held-out measurement. Record
both freeze revisions when unsealing. No reference repair is included.

Tests cover representative small Python maintenance contracts, boundaries,
invalid inputs and preserved behavior; this tiny owned set cannot establish
real-world or commercial repair reliability. A passing score is owned synthetic
evaluation evidence, never a paid-bounty success or revenue.

No baseline or candidate code has been executed by the authoring step. Static
catalog tests parse the source/tests without importing them. Actual baseline
and repaired execution must use the independently admitted digest-pinned Docker
route, immutable tests, existing budgets and replay receipts. No host execution,
dependency installation, new privileges, network or customer-code permission is
conferred by this catalog.
