# Opt-in statement repair

Purpose: improve bounded Python maintenance repairs without expanding paths,
execution capabilities, provider budgets or arbitrary-source admission. Existing
line protocol remains available. User explicitly authorizes routine design and
implementation decisions without repeated approval gates.

Options considered: physical-line prompt refinements preserve continuation
failures; full-function rewrites expand review surface; deterministic AST span
selection handles continuations while retaining narrow scope. Implement the
third as opt-in, verify against neutral cases before any model experiment.

Trusted caller supplies source path, digest and <=30 approved line anchors.
A nonexecuting AST catalog maps simple statements to whole physical spans and
If/While conditions to expression spans, rejecting ambiguous inline statements,
decorators, declarations and unsupported layouts. Model output stays <=3
{line,new} changes, <=400 bytes/3 physical lines each, <=3000 response bytes.
Apply disjoint replacements in reverse original offset order, preserve base
indentation and assignment bindings, then run the exact shared line-protocol
source capability/declaration checks. Reject semantic no-ops.

The repair loop starts each candidate from the pinned baseline, carries exact
rejection/test diagnostics, preserves validated partial sibling proposals,
tracks candidate/AST fingerprints, and avoids repeated candidate execution.
Every model call and rejection is evidence. No implicit protocol/provider
fallback, arbitrary command, downloaded code, private input or external delivery.

Acceptance: TDD neutral multiline, condition, binding, capability/scope and
retry negatives; complete existing regressions; independently authored frozen
owned evaluation separated from development; Docker admission and independent
credential-free replay; source/hash/usage accounting; existing model caps.
Owned results are synthetic and cannot establish real-world/commercial quality.
Private authorization remains metadata-only until separate execution approval.
